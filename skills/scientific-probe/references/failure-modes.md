# Scientific Probe Failure Modes

## Safe-answer collapse

Symptom: the agent converges on the mainstream explanation before surfacing consequential alternatives.

Correction: challenge the soft assumptions with the highest leverage and add a structurally different candidate only when it has a coherent mechanism and distinct prediction.

## Contrarianism theater

Symptom: an exotic explanation is added only to appear creative, without a mechanism or discriminating consequence.

Correction: require causal or mathematical coherence and a prediction that differs under a feasible probe.

## Premature formalization

Symptom: an early discovery problem is forced into binary hypotheses, a numerical threshold, and a long protocol before the relevant observables are known.

Correction: use DISCOVERY mode, define a compact search target and branch rule, and freeze only the current probe.

## Evidence paralysis

Symptom: the agent refuses to form a scoped working hypothesis or choose a reversible next probe until comprehensive or universal evidence exists.

Correction: separate the evidence needed for a strong claim from the evidence needed for the next action. State the local scope and assumptions, then run the cheapest probe capable of changing the decision.

## Local-pattern erasure

Symptom: a repeated local, regional, seasonal, taxonomic, or regime-specific pattern is dismissed because it is not yet a universal law.

Correction: treat the pattern as scoped evidence, encode its domain of validity, and test the nearest transfer boundary or competing explanation. Do not generalize it silently, but do not discard it merely for being local.

## Non-blocking design fixation

Symptom: file layout, framework choice, exhaustive edge cases, or a secondary analysis detail consumes the run even though it cannot change the current scientific interpretation.

Correction: record the assumption or deferral once, freeze only inference-relevant choices, and continue. Reopen the detail only when it reaches the current probe's critical path.

## Engineering substitution

Symptom: the run produces a polished framework, pipeline, or test suite but never defines evidence that would change the scientific state.

Correction: return to the discriminator and Probe Contract. Software readiness is not evidence.

## One-hypothesis confirmation

Symptom: the favored explanation is compared only with “nothing happens,” while a plausible artifact or competing mechanism predicts the same signal.

Correction: build the smallest credible alternative set and find an observation on which predictions differ.

## Hypothesis laundering

Symptom: an assumption introduced by preprocessing, simulation, or an observation operator is later described as an observed fact.

Correction: label it assumed or model-dependent and test the mapping separately when consequential.

## Metric or branch shopping

Symptom: many metrics, thresholds, samples, or exploratory branches are tried and only the favorable one is reported.

Correction: preserve the predeclared primary result; retain the full exploration log; require a new confirmatory contract.

## Underpowered minimalism

Symptom: the probe is small but incapable of resolving the difference relevant to the decision.

Correction: estimate the necessary resolution, sample size, tolerance, or effect scale. Increase only the dimension that supplies discriminatory power.

## Non-discriminating sweep

Symptom: a large parameter sweep is run even though all current candidates predict overlapping outcomes.

Correction: identify a contrast, limiting case, intervention, or diagnostic signature before scaling compute.

## Simulation-to-reality leap

Symptom: reproducing a pattern inside a model is treated as evidence that the modeled mechanism caused the real pattern.

Correction: mark the result model-dependent and seek an observation or intervention not guaranteed by the model assumptions.

## Leakage or population drift

Symptom: preprocessing, feature construction, filtering, or split logic lets target information enter the predictor or silently changes the evaluated population.

Correction: freeze population and preprocessing rules for confirmatory work, use leakage-resistant controls, and report the actual population.

## Apparatus ambiguity

Symptom: a null result cannot distinguish a weak hypothesis from failed measurement or implementation.

Correction: add the smallest positive or apparatus control.

## Surprise suppression

Symptom: evidence incompatible with every current candidate is treated as noise or repaired away.

Correction: preserve the anomaly, mark the probe unresolved or invalid, reopen the smallest assumption set, and create a new discovery contract.

## Premature stopping or endless continuation

Symptom: the run stops before the rule can be evaluated, or continues after the current probe has delivered its information.

Correction: make the stop or branch rule operational and report whether it was reached.
